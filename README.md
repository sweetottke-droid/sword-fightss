# Sword Fights on the Heights - multiplayer (Render)

1. Put this folder on GitHub (new repo, upload all files: server.js, package.json, render.yaml, public/index.html).
2. On render.com: New + > Web Service > connect the repo.
3. Settings: Runtime Node, Build Command `npm install`, Start Command `npm start`, Instance Type Free. (Or New + > Blueprint, which reads render.yaml.)
4. Deploy. Open the https://....onrender.com link and send it to your friends. No accounts needed.

The free plan sleeps after ~15 min idle; the first visit afterwards takes about a minute to wake up.
